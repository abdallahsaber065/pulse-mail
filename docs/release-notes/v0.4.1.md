Pulse Mail v0.4.1 — install, click Sign in with Google, done. No Cloud project of your own.

## What's new

**Sign in from the installer.** Official Windows, macOS, and Linux builds now include this project's Google sign-in, so you can open the app and click **Sign in with Google**. You do not need to create a Cloud project. v0.4.0 installers did not have that.

Google will still show **"Google hasn't verified this app"**. That's expected — the Gmail permission is restricted, unverified apps are capped at about **100 users**, and the warning stays until verification finishes. Choose **Advanced** → **Go to Pulse Mail (unsafe)**, then allow Gmail access.

**A website.** [abdallahsaber065.github.io/pulse-mail](https://abdallahsaber065.github.io/pulse-mail/) has the product page, [privacy policy](https://abdallahsaber065.github.io/pulse-mail/privacy/), and [terms](https://abdallahsaber065.github.io/pulse-mail/terms/). Static files, no cookies, no analytics.

**For people hacking on it.** `pnpm dev` opens a fictional mailbox so you can work on the UI without a Google account. That path is off in these installers.

## Install

Pick the file for your OS from this release:

- **Windows** (daily driver): `Pulse.Mail_0.4.1_x64-setup.exe` (per-user, no admin) or the `.msi`. SmartScreen may warn once — the installer isn't Authenticode-signed yet. **More info** → **Run anyway**.
- **macOS (Apple Silicon)**: `Pulse.Mail_0.4.1_aarch64.dmg` — **experimental and unsigned**. After dragging to Applications: right-click → Open the first time. Intel Macs are not built.
- **Linux**: `Pulse.Mail_0.4.1_amd64.AppImage` (self-updates), `Pulse.Mail_0.4.1_amd64.deb`, or `Pulse.Mail-0.4.1-1.x86_64.rpm` — **experimental**. Tray needs an appindicator; notification buttons work on GNOME/KDE.

Windows is the one that's been lived in. macOS and Linux compile and ship; they have not had a long run on real hardware yet.
