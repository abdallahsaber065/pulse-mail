Pulse Mail v0.4.4 — your Google sign-in stays put, and a reconnect is never undone by an
older session.

## What's new

**Sign-ins that stick.** When Google hands Pulse Mail a renewed sign-in credential, the
app now keeps it and uses it straight away instead of failing at the next mail check. A
reconnect made elsewhere — another window, or a development build running next to the
installed app — is picked up without restarting.

**One sign-in record per account.** Reconnecting now updates the account's existing
credentials instead of adding a second copy, so an older session can no longer overwrite
a newer sign-in, and signing out while a check is in flight can no longer bring the
removed credential back.

**Clearer when something is off.** If Google refuses the saved sign-in, the local log now
records Google's own reason, and Pulse Mail warns at sign-in when Google puts a time limit
on the credential — almost always a Cloud project still in "Testing". No tokens are
written to logs.

If Google itself revokes the grant (a password change, too many granted sign-ins on the
account, or access removed at myaccount.google.com), you will still be asked to sign in
again — that decision is Google's, not the app's. What changed is what happens next: the
new sign-in is saved, used immediately, and never overwritten by an older copy.

## Install

Pick the file for your OS from this release:

- **Windows** (daily driver): `Pulse.Mail_0.4.4_x64-setup.exe` (per-user, no admin) or the `.msi`. SmartScreen may warn once — the installer isn't Authenticode-signed yet. **More info** → **Run anyway**.
- **macOS (Apple Silicon)**: `Pulse.Mail_0.4.4_aarch64.dmg` — **experimental and unsigned**. After dragging to Applications: right-click → Open the first time. Intel Macs are not built.
- **Linux**: `Pulse.Mail_0.4.4_amd64.AppImage` (self-updates), `Pulse.Mail_0.4.4_amd64.deb`, or `Pulse.Mail-0.4.4-1.x86_64.rpm` — **experimental**. Tray needs an appindicator; notification buttons work on GNOME/KDE.

Windows is the one that's been lived in. macOS and Linux compile and ship; they have not
had a long run on real hardware yet. The sign-in changes compile and pass the project's
offline tests; the live account checklist is in
[docs/VERIFY-LIVE.md](https://github.com/abdallahsaber065/pulse-mail/blob/main/docs/VERIFY-LIVE.md).
